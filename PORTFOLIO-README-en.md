# Mateus Carniel Brambilla’s portfolio

Built with Vue 3, TypeScript and Vite. The application lives at the repository root.

Use Node `^22.18.0 || >=24.12.0` and npm:

```sh
npm ci
npm run dev
```

Validation and build:

```sh
npm test
npm run lint:check
npm run build
npm run preview
```

The build generates data from YAML, checks types, compiles the client and a temporary SSR bundle
in `dist-ssr/`, and renders static pages into `dist/`. Deploy **only `dist/`**.
No Node server is required in production.

## GitHub profile READMEs

This is the `matbdev/matbdev` repository: `README.md` presents the profile in Portuguese, and
`README-en.md` provides the English version. This file contains the website’s technical documentation.

Both profile READMEs are generated by `scripts/profileReadme.ts` during `npm run build:data`,
`npm run dev` and `npm run build`, using the same YAML data as the portfolio. Edit facts in the
corresponding `metadata/` modules; presentation headings and link labels live in
`profile.content.<locale>.readme` in `metadata/profile.yml`.

After editing YAML, run `npm run build:data` and include the updated READMEs in the same commit.
`npm test` checks that these files remain synchronized. The generator does not publish or create
commits automatically. Do not edit the profile READMEs manually.

The header includes the portfolio’s animated Tux, with a static alternative for reduced motion.
See the [asset sources and generation commands](docs/profile-mascot.md) (in Portuguese).

## SEO and agent discovery

- `/en/` and `/pt-BR/` contain complete HTML before JavaScript runs. `/` serves the default English version, with a canonical URL pointing to `/en/`.
- Each language has its own title, description, canonical URL, hreflang, Open Graph, Twitter metadata and JSON-LD.
- `robots.txt`, `sitemap.xml`, `llms.txt` and Markdown versions are generated during the build.
- `/en/index.md` and `/pt-BR/index.md` contain the profile, experience, projects, education, credentials and résumé links from the same YAML data.
- `llms.txt` is a complementary convention for agent discovery, with no guarantee of adoption or ranking. Indexable HTML remains the foundation.
- Previous links using `/?lang=en` and `/?lang=pt-BR` are still interpreted by the application. New links use the static routes.

Edit the domain and SEO copy in `metadata/site.yml`. Profile information and professional facts
remain in their corresponding YAML modules. Never edit generated artifacts manually.

## Deployment

Set your hosting provider’s working directory to the repository root, the build command to
`npm run build`, and the publish directory to `dist` (previously `web/dist`). The static server
must resolve `/en/` to `/en/index.html` and `/pt-BR/` to `/pt-BR/index.html`, preserving their
separate files. Avoid a rule that replaces every route with the root `index.html`.
Configure real HTTP 404 responses for nonexistent URLs.

After deployment, submit `https://matbdev.com/sitemap.xml` to Google Search Console and Bing
Webmaster Tools, and inspect the localized URLs. Indexing and inclusion in AI answers depend
on crawling and each service’s criteria.

See [AGENTS.md](AGENTS.md) and the [data and localization guide](docs/guia-i18n-e-dados.md)
(both in Portuguese).
